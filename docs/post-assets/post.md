【StudyHack】TopicScope · 选题雷达：可回查的科研选题工作台

**正文**

## 一、30 秒速览

**一句话**：TopicScope 是一个打开网页就能用的科研选题工作台——把一批文献聚成方向、把口径不一的指标换算成可比数字，再把判断整理成综述、体检报告与研究方案。

**三个不一样的地方**

1. **说边界，不说结论**：每条覆盖判定固定附一行「不能推出什么」，判定阈值在界面原样公开；小样本簇会被降级为「样本内稀疏 · 证据不足」，而不是硬给一个方向结论。
2. **算不出来就说算不出来**：26 个指标、四类任务，能换算的给公式，不能互推的（mIoU↔mDice 等 5 组）直接写清数学原因；公式由独立 Python 参考实现交叉验证，站内自检 50/50 通过。
3. **AI 说的每句话都能回查**：引用数字与证据 ID 逐条核对，对不上的标「引用无法定位」并列出未识别 ID；综述带 [n]↔GB/T 7714、质量门禁与自我对抗检查；导出文件头部自带完整检索快照（检索式、检索时间、去重、覆盖率）。

**关键数字**：540 篇离线快照（2018–2026）｜6 个方向簇｜26 个指标｜50/50 独立自检｜5 个 AI 动作（方向建议/综述/体检/方案/对话）｜在线检索实测返回 200 篇、去重后 199 篇，结果 12 小时共享缓存｜323 条自动化回归断言｜5 组导航 + 4 个子页。

**最快体验**：打开站点 → 点右上角「**演示模式**」→ 按 6 步动线跳转，3 分钟看完全部核心能力；对话框里附已知局限 Q&A 与可导出的录屏脚本。

## 二、3 分钟评审体验动线

不用自己找入口：点右上角「演示模式」，里面有三个预置方向（默认快照 / 增长窗口 / 稀疏方向）、6 步动线与每步的「跳转」按钮，还有已知局限 Q&A 和录屏脚本。

1. **检索与雷达**：看每条判定附的「不能推出什么」，界面原样公开阈值（10% / 12% / 60% 与 size<10 的稀疏规则）。
2. **指标口径对齐**：演示 mIoU↔mDice 为什么换不了，打开自检面板看 50/50 通过。
3. **论文与证据**：打开 nnU-Net 证据卡，看六维评分拆解与「当前材料无法判断」清单。
4. **文献综述**：讲本地质量门禁（引用 / 交织 / 分寸）与自我对抗检查。
5. **选题体检**：演示「拒绝并转向」的致命缺陷审计与完整性自检。
6. **研究档案**：载入存档、导出 JSON 查看检索快照元数据。

想自己走一遍：顶部输入研究方向 → 「在线检索」（**无需任何配置**）→「生成方向建议」→ 找一条标「引用无法定位」的建议，切到关键词共现词对列表当场核对这个数字——把「可回查」变成一个可验证的动作，而不是一句口号。

## 三、作品是什么 · 核心能力

导航按真实科研顺序收敛为五组：**检索与雷达 / 论文与证据 / 研究对话 / 方案与档案（内含 文献综述 · 选题体检 · 研究方案 · 研究档案）/ 指标口径对齐（独立工具入口）**。

**架构与隐私（统一口径）**：分析计算全部在浏览器本地（TF-IDF、球面 k-means、共现、覆盖判定、指标换算、六维评分都不上传文献内容）；在线检索与 AI 生成走同源 Edge Function：检索由服务端请求 OpenAlex 主源 + Semantic Scholar 第二主源（Crossref 兜底），结果缓存 12 小时供所有访客共享；AI 生成把所选统计数字、论文标题与摘要节选、以及你勾选的已核对证据发给站点自带的模型服务，**不送全文**。服务端已配置检索 key，**开箱即用、不需要填任何 key**；个人 OpenAlex key 只在服务端不可用、浏览器直连回退时才用得到，且只保存在本机 localStorage。模型 key 只从服务端 Secret（`QWEN_API_KEY`）读取，不进入源码、构建产物或任何响应。换方向直接点「在线检索」即可；顶部另有「强制刷新」用于忽略 12 小时缓存重新取数。

**组一 · 检索与雷达**：输入一个研究方向，它把相关文献聚成若干簇，给出覆盖度判定，并明确告诉你每个判定「不能推出什么」。每个方向卡片带一张按年发文量迷你趋势图（近三年深色高亮）。

**组一 · AI 研究方向建议（可回查）**：模型只拿到样本的数字（簇统计 + 共现词对 + 语料规模），温度 0，禁止引用数据外事实。AI 引用的数字与证据 ID 都会回查：能对上的标「证据与数字可定位」，对不上的标「引用无法定位」并列出未识别的 ID，不存在的 ID 直接丢弃；正文里的提升度/占比/被引等数字另与统计白名单逐一比对，对不上的单独高亮标「正文数字未核对」。每条建议带「体检这个想法」一键跳体检，整份可导出 Markdown。

最典型的例子是 mIoU → mDice：IoU→Dice 是逐类非线性变换，先平均再变换与先变换再平均结果不同，只有一个 mIoU 无法唯一确定 mDice，必须拿到逐类 IoU。工具把这个「换不了」和原因直接写在界面上——我认为这比一个看起来能用、其实会误导人的换算更有价值。

## 四、方法与验证（做了什么、没做什么）

「验证」要说清边界：自动化回归只能证明「实现与公开规则一致」，不能证明「规则本身对」。

**已做的验证**

- **指标交叉验证**：50 项自检期望值由我独立写的 Python 参考实现（`dev/selfcheck_reference.py`）算出，与 TypeScript 只共享数学定义、不共用代码路径；站内面板 50/50 通过，可点开看每个用例的期望值与实际值。
- **判定阈值稳定性回归**：对 10% / 12% / 60% 阈值做 ±20% 扰动，在稀疏簇夹具上重跑，判定不翻转（翻转 0 次），并断言 6/6 组扰动确实生效。整个 `scripts/regression.mjs`（`npm run regression`）共 **323 条断言**，覆盖检索去重、证据引用解析、方案输出校验、综述门禁、存档合并、服务端检索（多源合并/429 降级/共享缓存/Crossref 兜底）、稀疏簇判定、阈值稳定性、输入校验、正文数字回查、导出头部元数据，全程不触网。
- **本地门禁**：综述质量门禁、体检完整性自检、方案解析与证据白名单、逻辑链逐环对照，每次生成后前端本地跑。
- **可复现性**：固定种子 k-means 结果可复现；导出与存档带完整检索快照；AI 引用逐条回查、未识别 ID 显式标出。
- **线上边界点测（真实站点）**：空检索禁用、0 命中不产噪声、稀疏簇降级、导师汇报不推荐噪声簇、对话自动聚焦与送入清单、413 内联报错、断网重开并切换页签、方案对照表/复现包/输入快照渲染、演示模式四块齐全，控制台零报错。

**未做的验证（不夸大）**：没有人工金标准标注（未人工标 30–50 篇方向作对照），没有聚类纯度/ARI，没有判定与专家标注一致率；在线检索是偏向性抽样（按相关度返回、快照按年分桶），未与 OpenAlex 全量年度计数对比，样本占比不能当领域真实产出比例。所以覆盖判定、六维评分与体检结论仍是**启发式线索，不是经过人工验证的结论**；最终判断在你和导师手里。

## 六、用 Qoder 做出来的过程

**第 1 步 · 把「选题」拆成两个可验收动作，再按我的设计稿扩成链路**：能不能从一批文献看出方向分布并给空白判断；能不能把一个指标换算成另一口径。之后我写设计稿把「看方向」扩成「检索溯源 → 判定 → 可回查建议 → 文献库/评分 → 证据卡 → 15 节方案 → 档案」。

## 七、边界与已知局限

**已经做的验证**：26 指标由独立 Python 参考实现交叉验证（50/50）；判定阈值界面公开且可复算；固定种子 k-means 可复现；导出与存档带完整检索快照；AI 引用逐条回查；边界输入与异常路径有明确提示；323 条回归断言。

**方法与数据的边界**：聚类是无监督的，长尾语料会碎（`counting · processing` 4 篇实为微生物计数，已降级为「样本内稀疏 · 证据不足」而非方向结论）；判定阈值是启发式、未经领域专家校验，只作线索；共现基于标题/关键词/摘要，不读全文、不区分词义；离线快照只覆盖一个检索式；六维评分权重与体检框架是自定义/改编，不是学界共识；综述、体检、方案都是结构化草稿，不是同行评议结论；体检能力画像靠自报、未经核验，新颖性只对照当前样本，「拒绝并转向」也可能只是样本覆盖不足。

**下一步**：扩大检索式覆盖；补人工标注的方向金标准做一致性验证；持续把新增模块纳入离线预缓存与回归。

**署名与其他**：体检/综述纪律/逻辑链/审稿速查改编自 HKUSTDial/Supervisor-Skills（CC-BY-4.0），界面与导出已署名，改编做了简化不等同原项目完整评估；指标模块做口径换算与解释，不做样本级曲线/置信区间/统计显著性；站点右下角保留平台依法加注的「Made with Qoder」标识。
