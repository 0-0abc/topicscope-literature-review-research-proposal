## 一、30 秒速览

**一句话**：TopicScope 是一个打开网页就能用的科研选题工作台——把一批文献聚成方向、把口径不一的指标换算成可比数字，再把判断整理成综述、体检报告与研究方案。

**三个不一样的地方**

1. **说边界，不说结论**：每条覆盖判定固定附一行「不能推出什么」，判定阈值在界面原样公开；小样本簇会被降级为「样本内稀疏 · 证据不足」，而不是硬给一个方向结论。
2. **算不出来就说算不出来**：26 个指标、四类任务，能换算的给公式，不能互推的（mIoU↔mDice 等 5 组）直接写清数学原因；公式由独立 Python 参考实现交叉验证，站内自检 **56 项**；本轮还修复了二分类计数转混淆矩阵的 TP/TN、FP/FN 错位，以及分割编辑后 union 未重算的问题。
3. **把「可回查」说清楚，不夸大**：方向建议、综述、体检、方案中的结构化数字与证据 ID 按实际送入的统计和证据白名单回查；综述另有 [n]↔GB/T 7714 对照、质量门禁与自我对抗检查。研究对话提供按回答冻结的引用元数据徽标和「本次实际送入」论文清单，**不宣称完成对话全文的数字白名单审计**。导出文件头部带检索快照（检索式、检索时间、去重、覆盖率）。

**关键数字**：540 篇离线快照（2018–2026）｜6 个方向簇｜26 个指标｜56 项指标自检｜5 个 AI 动作（方向建议/综述/体检/方案/对话）｜**474 条自动化回归断言全部通过**｜5 组导航 + 4 个子页。

**最快体验**：打开站点 → 点右上角「**演示模式**」→ 按 6 步动线跳转，3 分钟看完全部核心能力；对话框里附已知局限 Q&A 与可导出的录屏脚本。

## 二、3 分钟评审体验动线

不用自己找入口：点右上角「演示模式」，里面有三个预置方向（默认快照 / 增长窗口 / 稀疏方向）、6 步动线与每步的「跳转」按钮，还有已知局限 Q&A 和录屏脚本。

1. **检索与雷达**：看每条判定附的「不能推出什么」，界面原样公开阈值（10% / 12% / 60% 与 size<10 的稀疏规则）。
2. **指标口径对齐**：演示 mIoU↔mDice 为什么换不了，打开自检面板查看 56 项用例与独立参考期望值。
3. **论文与证据**：打开 nnU-Net 证据卡，看六维评分拆解与「当前材料无法判断」清单。
4. **文献综述**：讲本地质量门禁（引用 / 交织 / 分寸）与自我对抗检查。
5. **选题体检**：演示「拒绝并转向」的致命缺陷审计与完整性自检。
6. **研究档案**：载入存档，查看冻结的方案输入、人工修订状态与对话引用元数据，导出 Markdown / JSON 核对检索快照。

想自己走一遍：顶部输入研究方向 →「在线检索」（**无需任何配置**）→「生成方向建议」→ 展开结构化数字与证据 ID 的回查结果，再用关键词共现词对列表核对占比、提升度等统计；切到「研究对话」，展开任一回答的「本次实际送入」，核对引用徽标与真实送入来源。这里验证的是**定位与来源一致性**，不是「AI 每句话都经完整事实审计」。

## 三、作品是什么 · 核心能力

导航按真实科研顺序收敛为五组：**检索与雷达 / 论文与证据 / 研究对话 / 方案与档案（内含 文献综述 · 选题体检 · 研究方案 · 研究档案）/ 指标口径对齐（独立工具入口）**。

**架构与隐私（统一口径）**：TF-IDF、球面 k-means、共现、覆盖判定、指标换算、六维评分等分析计算在浏览器本地完成，不上传文献内容；在线检索与 AI 生成走同源 Edge Function。检索由服务端**并行请求 OpenAlex 与 Semantic Scholar 双主源**后合并去重；英文检索时 Crossref 只在 OpenAlex 故障时兜底，中文检索时额外用中文原题补充 Crossref 中文期刊。S2 专属 key 从服务端 Secret 读取，按 **1 req/s 串行化**请求；未配置时退回匿名共享池。服务端共享缓存：**成功结果 12 小时，0 命中或任一来源故障只缓存 2 分钟**；「强制刷新」可绕过缓存。

AI 生成把所选统计数字、论文标题与摘要节选、以及勾选的已核对证据发给站点自带的模型服务，**不送全文**；服务端实际调用 `temperature: 0.4`，并非 0。**中文检索词会先发往模型服务翻译成英文**，再进行中英双语检索：OpenAlex 用「英文｜中文」并列，S2 用英文，Crossref 按需补充中文期刊；原词、译词、来源计划与翻译局限写入检索快照。译词会核对 `C++`、`nnU-Net` 等算法/模型/数据集/缩写专名，被漏掉的自动补回检索词。机器翻译仍可能有偏差，因此界面同时保留原词与译词，不把译词当作人工审定结果。

站点已配置检索 key，**开箱即用、访客无需填任何 key**；可选个人 OpenAlex key 只在服务端不可用、浏览器直连回退时使用，且只存在本机 localStorage。模型 key 只从服务端 Secret（`QWEN_API_KEY`）读取，不进入源码、构建产物或任何响应。模型输出使用纯 React 元素安全渲染 Markdown，支持**粗体、列表、行内代码、代码围栏、表格与引用**，**不使用 `innerHTML`**；HTML 与危险协议保持纯文本。对话回答中误塞的 `refs` / `evidenceIds` / 证据 ID 会从展示正文清洗并恢复为独立结构化字段，旧存档渲染与导出同样生效。

**组一 · AI 研究方向建议（结构化回查）**：模型获得簇统计、共现词对、语料规模与当前论文元数据，服务端实际温度 `0.4`，提示词禁止引用数据外事实。正文中的提升度/占比/被引等数字与统计白名单比对，证据 ID 按送入清单定位；对不上的标「引用无法定位」或「正文数字未核对」，不存在的 ID 直接丢弃。这套检查针对**结构化数字与证据引用**，不等于验证模型所有自然语言事实。每条建议带「体检这个想法」一键跳体检，整份可导出 Markdown。

**组三 · 研究对话**：模型只看到当前聚类统计 + 选定论文标题/摘要节选 + 勾选的已核对证据；**聚焦方向按提问关键词自动匹配**，页面列出本次实际送入的论文清单与来源，未送全文。每条回答带引用徽标，徽标按该回答实际送入并冻结的来源显示「摘要 / 标题 / 年份 / 人工核对」；只有本次送过的人工核对字段才标人工核对。判断不了的单标「无法判断」；认可的回答一键「加入方案草稿」进入方案上下文。

本轮审计明确：**对话不是完整数字白名单审计**，其保障是引用元数据冻结、来源徽标和实际送入清单可核对。回答冻结时保存 paperId、标题、来源、核对字段与本次送入论文列表，之后证据标注或样本变化不会反向篡改旧回答；这些元数据随 IndexedDB 档案保存，导出的 Markdown 离线也可读，并逐条列出实际送入来源。模型若把引用 JSON 或证据 ID 误写进 `answer`，服务端与前端都会清洗，引用仍保留为独立徽标，不再直接显示机器元数据。

![研究对话：本次送入清单、冻结引用徽标、无法判断标注、加入方案草稿](https://static.tianchi.aliyun.com/userimg/1095281234536/2026-11-13/KYGnHSvQvexKvgx8.png)

**组四 · 文献综述草稿**：每方向选被引最高 4 篇（≤24 篇），只允许引用编号文献，[n]↔GB/T 7714 一一对应；按主题综合叙述而非逐篇罗列；三条写作纪律（措辞按证据强度校准 / 每段交织对比≥2 篇 / 自我对抗检查）；生成后本地质量门禁（引用 / 交织 / 分寸）逐条标「通过 / 存疑 / 不足」，未被引用的编号单列候选；代表文献经相关性过滤，跨域噪声不混入。正文结构化数字按送入统计回查，Markdown 由安全渲染器呈现。

![文献综述：主题综合叙述 + 本地质量门禁（引用 / 交织 / 分寸）](https://static.tianchi.aliyun.com/userimg/1095281234536/2026-11-13/5i3JwvrfNKyFesmg.png)

**组四 · 选题体检**：固定顺序「致命缺陷审计 → 生命周期与能力匹配 → 五维评分（更高/更快/更强/更省/更广，5 分起步给依据才加分）→ 范式转移探测 → 可行性风险 → 先做的三件事」；新颖性只对照样本内编号真实文献；能力画像自报、未经核验（界面写明）；只选方向不写想法可做方向级体检，默认值明确标注；三档结论 + 本地完整性自检（致命缺陷却「接受」自动降为「拒绝并转向」；「强烈接受」但无一维 ≥8 降为「修改后接受」，降级原因写在结论旁）；正文数字按统计白名单回查；导出附新颖性核对文献。框架改编自 Supervisor-Skills idea-evaluator（CC-BY-4.0，界面与导出署名）。

- **可复现性**：固定种子 k-means 在同一输入上可复现；导出与存档带检索快照；结构化数字与证据 ID 显式标出未识别项；对话冻结实际送入清单与引用元数据；方案冻结生成输入并记录人工修订。

**未做的验证（不夸大）**：没有人工金标准标注（未人工标 30–50 篇方向作对照），没有聚类纯度/ARI，没有判定与专家标注一致率；在线检索是偏向性抽样（按相关度返回、快照按年分桶），未与 OpenAlex 全量年度计数对比，样本占比不能当领域真实产出比例。结构化回查保证的是数字/ID 能定位到输入，**不是对 AI 全部陈述的事实审计**；对话只保证引用元数据与实际送入清单一致。覆盖判定、六维评分与体检结论仍是**启发式线索，不是经过人工验证的结论**；最终判断在你和导师手里。

## 五、这一版修复了什么（本轮审计修复，均可现场复现）

**2026-11-24 审计重点：不是再加功能，而是把能力边界、隐私去向、状态一致性与计算正确性逐项对齐。**

- **收窄回查口径**：方向建议/综述/体检/方案的结构化数字与证据 ID 按白名单回查，对话明确为冻结引用徽标 + 实际送入清单，不做完整数字白名单审计。
- **更正模型参数**：服务端实际 `temperature: 0.4`，方案复现包同步记录。
- **补全中文检索隐私链路**：中文检索词会发模型服务翻译，再以 OpenAlex 中英并列、S2 英文、Crossref 中文补充检索；原词/译词/局限进快照，`C++`、`nnU-Net` 等专名核对并补回。
- **校正多源检索口径**：OpenAlex 与 S2 双主源并行；Crossref 仅在 OpenAlex 故障时兜底，中文时补充中文期刊；S2 专属 key 按 1 req/s 串行。
- **校正缓存口径**：成功结果共享缓存 12 小时；0 命中或任一来源故障只缓存 2 分钟，避免临时故障锁死后续检索。
- **安全渲染**：Markdown 支持粗体/列表/代码/表格/引用，纯 React 元素渲染，无 `innerHTML`；HTML 与危险协议不执行；对话 answer 内重复的引用 JSON 与证据 ID 自动清洗并恢复为独立字段。
- **检索竞态与旧样本**：过期响应不得覆盖最新请求；失败与 0 命中清空旧 papers/radar/report，不再把上一轮样本当当前结果。
- **对话冻结与离线导出**：引用元数据和本次实际送入论文列表随回答冻结、存档、导出；旧回答不随当前证据标注变化而误标来源。
- **方案修订与白名单**：人工修订持久化，恢复冻结输入；references/evidenceIndex 由服务端按当前论文/证据白名单重建，人工保存时再按冻结白名单重建。
- **指标计算修复**：混淆矩阵固定 `[[TN, FP], [FN, TP]]`；分割编辑后按交集与两面积重算 union，并纳入独立自检。
- **离线升级**：Service Worker 按构建内容 hash 升级，构建清单覆盖懒加载模块，避免旧 SW 拦截新资源。
- **验证收口**：删除过时结果数字，当前 `npm run regression` 为 **474/474 通过**；指标自检写为 **56 项**。

此前已落地并保留的边界设计：小簇不再硬下结论；空/无效检索校验与 0 命中提示；超长请求提示 96KB 上限；403/429/504 内联报错；导出头部完整检索快照；演示模式与强制刷新；全量离线预缓存与真实来源徽标。

## 七、边界与已知局限

**已经做的验证**：26 指标由独立 Python 参考实现交叉验证（56 项）；判定阈值界面公开且可复算；固定种子 k-means 在同一输入上可复现；导出与存档带检索快照；结构化数字与证据 ID 显式回查；对话引用元数据与实际送入清单冻结；边界输入与异常路径有明确提示；474 条回归断言全部通过。

**方法与数据的边界**：聚类是无监督的，长尾语料会碎（`counting · processing` 4 篇实为微生物计数，已降级为「样本内稀疏 · 证据不足」而非方向结论）；判定阈值是启发式、未经领域专家校验，只作线索；共现基于标题/关键词/摘要，不读全文、不区分词义；离线快照只覆盖一个检索式；六维评分权重与体检框架是自定义/改编，不是学界共识；综述、体检、方案都是结构化草稿，不是同行评议结论；体检能力画像靠自报、未经核验，新颖性只对照当前样本，「拒绝并转向」也可能只是样本覆盖不足。

**检索与隐私边界**：中文译词由模型服务生成，可能有误译；OpenAlex/S2 偏向相关度检索，Crossref 主要补元数据与中文期刊，不能覆盖全量；0 命中只表示本次多源检索未返回可用结果，不代表领域没有研究；S2 专属速率约 1 req/s，会增加检索等待；服务端缓存会暂存检索结果，AI 请求会发送所选统计、标题/摘要节选与已核对证据，不发送论文全文；本地档案与证据标注留在本机，清除浏览器数据会删除本地存档，重要结果请导出。
